About BookHead AI

An intelligent shelf-to-catalogue engine for ardent readers and librarians alike — powered entirely by open source AI models.

What it does

One app. Two superpowers.

📖

For Readers

Snap a photo of any bookshelf. BookHead AI reads every spine, looks up each book, and surfaces the title that best matches your mood, favourite genres, and preferred length — so your next great read is never more than a photograph away.

🏛️

For Librarians

Upload photos of an entire library. The app automatically identifies every book on every shelf, genre-codes each entry, enriches it with metadata from the Google Books API, and exports a fully structured, download-ready catalogue — no manual data entry required.

How it works

The AI Pipeline

Every image you upload travels through a six-stage intelligence pipeline before a single result reaches your screen.

01

Book Detection Faster R-CNN

A Faster R-CNN object-detection model scans the shelf photograph and draws a precise bounding box around every individual book spine it finds — even on crowded, cluttered shelves.

02

Spine OCR PaddleOCR

Each cropped spine is fed through PaddleOCR's two-stage pipeline: a text-detection model locates text regions, then a text-recognition model transcribes the characters — handling rotated, embossed, and foil-stamped typography.

03

Metadata Lookup Google Books API

The raw OCR text is pre-processed and cleaned, then used to query the free Google Books API. Candidate records — title, author, description, page count, genre labels, cover thumbnail — are pulled for each book. Fuzzy matching against the OCR string selects the best-fitting record.

04

Summary Generation Gemma-2B LLM

Google's Gemma-2B language model distils the book's description into a concise, reader-friendly summary — consistent in tone and length regardless of how verbose or sparse the source description is.

05

Genre Classification all-MiniLM-L6-v2

Each book is matched against a curated master list of genre labels and codes. The all-MiniLM-L6-v2 sentence-embedding model vectorises both the candidate genre labels and the book's own description, then picks the closest genre by cosine similarity — no hand-written rules needed.

06

Personalised Ranking all-MiniLM-L6-v2

Reader preferences (genres, mood, length) are embedded alongside every book's metadata. A composite similarity score — weighting genre match, mood alignment, description relevance, and length fit — is computed for each title, and the shelf is re-ranked from most to least relevant.

Under the hood

5 Models. One Seamless Flow.

BookHead AI chains five specialised open models — no single model does everything, but together they cover perception, language, and semantics.

🔍
Faster R-CNN
Object Detection

Localises and crops individual book spines from shelf photos with high precision.

👁️
PaddleOCR · Detection
Text Localisation

Finds text line regions within each cropped spine image.

🔤
PaddleOCR · Recogniser
Text Recognition

Converts detected text regions into UTF-8 strings — handles stylised and rotated type.

✍️
Gemma-2B
LLM · Summarisation

Generates crisp, consistent book summaries from raw API descriptions.

🧮
all-MiniLM-L6-v2
Sentence Embeddings · Matching

Powers both genre classification and personalised recommendation via vector similarity.
